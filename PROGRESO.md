# PROGRESO — qué funciona y cómo probarlo

## Cómo ejecutar
- Web: `flutter build web` y `node tool/serve_web.mjs 5500` → http://localhost:5500
- Windows: `flutter run -d windows`
- Tests: `flutter analyze` y `flutter test`
